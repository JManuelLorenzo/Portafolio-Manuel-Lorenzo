EJERCICIO 1: Análisis de GeneradorDatosGenericos.java

1) ¿Cómo se genera un vector monótonamente ascendente?

El método generarDatosAscendentes crea un arreglo donde cada posición almacena su propio índice como valor. Esto significa que:

  • En la posición 0 se guarda el valor 0
  • En la posición 1 se guarda el valor 1
  • Y así sucesivamente hasta completar el arreglo

El resultado es una secuencia perfectamente ordenada de forma creciente: [0, 1, 2, 3, …, n-1]

2) ¿Cómo se genera un vector monótonamente descendente?

El método generarDatosDescendentes utiliza una fórmula inversa. Para cada posición i, calcula el valor como (tamañoMaximo - (i+1)). Esto produce:

  • Primera posición: tamañoMaximo - 1
  • Segunda posición: tamañoMaximo - 2
  • Última posición: 0

Generando una secuencia decreciente perfecta: [n-1, n-2, n-3, …, 1, 0]

3) ¿Cómo se genera un vector con valores aleatorios? ¿Pueden existir claves repetidas? ¿Cuál es el orden del tiempo de ejecución?

El método generarDatosAleatorios implementa una permutación aleatoria:

  • Utiliza un arreglo booleano para marcar posiciones ya ocupadas
  • Para cada valor i (de 0 a n-1), busca una posición aleatoria disponible
  • Si la posición está ocupada, aplica sondeo lineal hasta encontrar una libre

Características importantes:

  • NO pueden existir claves repetidas: cada valor de 0 a n-1 aparece exactamente una vez
  • Complejidad temporal: O(n²) en el peor caso, debido al sondeo lineal cuando quedan pocas posiciones libres
  • Resultado: una permutación aleatoria de los números [0, 1, 2, …, n-1]

4) ¿Cuántos elementos contiene el vector de datos generado? ¿Cómo modificar para que sea parametrizable?

Actualmente el código ya es parametrizable - cada método recibe tamañoMaximo como parámetro. Sin embargo, existe una constante TAMANIO_MAX = 5 que no se utiliza en los métodos mostrados.

Para usar la clase:

GeneradorDatosGenericos generador = new GeneradorDatosGenericos();
int[] datos = generador.generarDatosAleatorios(100); // Vector de 100 elementos

5) ¿Cómo podemos verificar que un conjunto está ordenado? ¿Cuál sería el orden del tiempo de ejecución?

El método estaOrdenado en TClasificador.java implementa esta verificación:

  • Recorre el arreglo comparando cada elemento con su sucesor
  • Si encuentra algún par donde el elemento anterior es mayor que el siguiente, retorna false
  • Si completa el recorrido sin encontrar inversiones, retorna true

Complejidad: O(n) - debe examinar cada elemento una vez en el peor caso
